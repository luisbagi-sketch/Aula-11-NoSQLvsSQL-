# API de Produtos

Projeto de estudo com uma API feita em Express e uma interface React que consulta e exibe uma lista de produtos. Os dados são armazenados em um array no código.

**Autor:** Luis Gustavo Guisone Bagi

## Como executar

Na raiz do projeto, instale as dependências e inicie a API:

```bash
npm install
npm start
```

O comando `npm start` executa `node index.js`. A API fica disponível em `http://localhost:3000`.

Em outro terminal, inicie a interface React:

```bash
cd api-express-react
npm install
npm run dev
```

Mantenha a API ligada enquanto usa a interface.
